# Ejercicios básicos de React

Los siete ejercicios están en `src/Ej1.tsx` a `src/Ej7.tsx`. `App.tsx` muestra todos con su título.

## Ejecutar

Con Node.js 22.12 o superior:

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

Los datos de los ejercicios se guardan en memoria y se reinician al recargar.
